# asset-app

주식·ETF 포트폴리오와 공제회·예적금·연금을 한곳에서 관리하는 개인 자산관리 웹 앱입니다.
서버 없이 동작하며, 모든 데이터는 사용하는 사람의 브라우저(LocalStorage)에만 저장됩니다.

> 이 앱은 투자 권유가 아닌 참고용 도구입니다.

## 로컬에서 실행하기

빌드 과정이 없습니다. 저장소 폴더에서 정적 서버를 띄운 뒤 브라우저로 엽니다.

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. (ES Modules를 쓰기 때문에 `index.html`을 파일로 바로 열면 동작하지 않습니다.)

## 테스트

계산·저장 로직은 Node 내장 테스트 러너로 검사합니다. (Node 18 이상)

```bash
npm test
```

## 앱이 보내는 외부 요청

개인 데이터는 브라우저 밖으로 나가지 않습니다. 앱이 하는 외부 요청은 두 가지뿐입니다.

- 사용자가 설정한 구글 시트 웹 앱 주소로의 시세 GET 요청
- 차트를 그릴 때 jsDelivr CDN에서 Chart.js 4.4.1을 내려받는 요청 — 버전을 고정하고
  무결성 검사(SRI)를 걸어 두어, 파일이 바뀌어 있으면 실행하지 않고 목록으로만 보여줍니다.

## 구글 시트로 시세 자동 연동

현재가와 달러 환율은 각자 만든 구글 시트(`GOOGLEFINANCE`)에서 받아옵니다.
설정 방법은 [docs/SHEET_SETUP.md](docs/SHEET_SETUP.md)에 있고, 앱의 설정 → '연결 가이드 보기'에서도 볼 수 있습니다.
시트 주소가 없으면 직접 입력한 현재가로 계산합니다.

## 보유 종목 CSV 붙여넣기 형식

첫 줄은 제목 줄입니다. `종목명, 티커, 수량, 평단가`는 꼭 필요하고 나머지는 선택입니다.
엑셀·구글 시트에서 표를 복사해 붙여넣어도 됩니다(탭 구분).

```
종목명,티커,종류,통화,수량,평단가,계좌,자산군,국가,섹터
삼성전자,KRX:005930,주식,KRW,10,61000,일반,성장주,한국,기술
QQQ,NASDAQ:QQQ,ETF,USD,3,450,일반,성장주,미국,기술:50;통신:15;소비재:35
```
