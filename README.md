# asset-app

주식·ETF 포트폴리오와 공제회·예적금·연금을 한곳에서 관리하는 개인 자산관리 웹 앱입니다.
서버 없이 동작하며, 모든 데이터는 사용하는 사람의 브라우저(LocalStorage)에만 저장됩니다.

> 이 앱은 투자 권유가 아닌 참고용 도구입니다.

## 로컬에서 실행하기

빌드 과정이 없습니다. 저장소 폴더에서 정적 서버를 띄운 뒤 브라우저로 엽니다.

```bash
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000> 을 엽니다. (ES Modules를 쓰기 때문에 `index.html`을 파일로 바로 열면 동작하지 않습니다.)

## 테스트

계산·저장 로직은 Node 내장 테스트 러너로 검사합니다. (Node 18 이상)

```bash
npm test
```

## 배포 (GitHub Pages)

저장소를 GitHub Pages로 공개하면 휴대폰·PC에서 주소로 열고 홈 화면에 앱처럼 추가할 수 있어요.
순서는 [docs/DEPLOY.md](docs/DEPLOY.md)에 있습니다. 업데이트를 올려도 각자 브라우저에 저장된 데이터는 그대로예요.

## 데이터 백업과 옮기기

설정 → 내 데이터에서 백업 파일(JSON)을 내려받고, 다른 기기·브라우저에서 "백업 파일로 복원"으로 옮길 수 있어요.
백업 파일에는 개인 자산 정보가 들어 있으니 저장소에 올리지 마세요 (`.gitignore`가 `*backup*.json`, `asset-app-*.json`을 막아 둠).

## 종목 목록과 자동 입력

보유 종목을 추가할 때 종목명(한글 이름·종목코드도 됨)을 치면 `data/stocks.json`에서 후보를 보여주고,
고르면 티커·종류·통화·국가·섹터·자산군·ETF 분산 정도를 채웁니다. 목록은 앱 파일과 함께 올라가 있어서 검색 내용이 밖으로 나가지 않습니다.

- 목록 만들기: `npm run build:stocks` (국내는 네이버 금융의 업종별 종목·ETF 목록, 미국은 S&P500·미국 상장 목록 공개 데이터셋에서 받음)
- 매달 2일 GitHub Actions(`종목 목록 갱신`)가 새로 만들어 저장합니다. Actions 탭에서 바로 실행할 수도 있어요.
- 자료를 받지 못한 부분은 지난 목록을 그대로 씁니다. ETF의 업종 비율은 지수 구성을 바탕으로 한 대략값입니다.

## 앱이 보내는 외부 요청

개인 데이터는 브라우저 밖으로 나가지 않습니다. 앱이 하는 외부 요청은 두 가지뿐입니다.

- 사용자가 설정한 구글 시트 웹 앱 주소로의 시세 GET 요청
- 차트를 그릴 때 jsDelivr CDN에서 Chart.js 4.4.1을 내려받는 요청 — 버전을 고정하고
  무결성 검사(SRI)를 걸어 두어, 파일이 바뀌어 있으면 실행하지 않고 목록으로만 보여줍니다.

오프라인용 서비스 워커(`sw.js`)는 앱 파일과 Chart.js만 브라우저 안에 저장해 두고, 시세 요청은 건드리지 않습니다.

## 구글 시트로 시세 자동 연동

현재가와 달러 환율은 각자 만든 구글 시트(`GOOGLEFINANCE`)에서 받아옵니다.
설정 방법은 [docs/SHEET_SETUP.md](docs/SHEET_SETUP.md)에 있고, 앱의 설정 → '연결 가이드 보기'에서도 볼 수 있습니다.
시트 주소가 없으면 직접 입력한 현재가로 계산합니다.

## 보유 종목 CSV 붙여넣기 형식

첫 줄은 제목 줄입니다. `종목명, 티커, 수량, 평단가`는 꼭 필요하고 나머지는 선택입니다.
엑셀·구글 시트에서 표를 복사해 붙여넣어도 됩니다(탭 구분).
ETF는 `ETF 분산` 열에 `시장 전체형` / `업종·테마형` / `집중형`을 적을 수 있고, 비우면 종목명으로 짐작합니다.

```
종목명,티커,종류,통화,수량,평단가,계좌,자산군,국가,섹터
삼성전자,KRX:005930,주식,KRW,10,61000,일반,성장주,한국,기술
QQQ,NASDAQ:QQQ,ETF,USD,3,450,일반,성장주,미국,기술:50;통신:15;소비재:35
```
