앱이 주식·ETF의 **현재가와 달러 환율을 자동으로** 받아오게 하는 방법이에요. 처음 한 번만 하면 되고, 10~15분쯤 걸려요.

> **꼭 지켜 주세요** — 시트에는 **티커(종목 코드)만** 적어요. 수량·평단가·금액 같은 내 정보는 시트에 적지 마세요. 그런 정보는 내 브라우저에만 저장돼요.

## 어떻게 동작하나요?

1. 내 구글 시트에 티커를 적으면, 구글 시트의 `GOOGLEFINANCE` 함수가 현재가를 채워요.
2. 시트에 붙인 작은 코드(Apps Script)가 그 가격을 앱이 읽을 수 있는 형태로 보여줘요.
3. 앱은 그 주소에서 가격을 **받아오기만** 해요. 앱이 시트로 보내는 정보는 없어요.

구글 금융 시세는 실제보다 **최대 20분 정도 늦을 수** 있어요.

## 1단계. 시트 만들기

### 방법 A — 공유받은 템플릿이 있을 때

1. 앱을 알려준 사람에게 받은 템플릿 링크를 열어요.
2. **사본 만들기**를 눌러요. 내 구글 드라이브에 시트와 코드가 함께 복사돼요.
3. 코드와 기본 틀이 이미 들어 있으니 2~3단계는 건너뛰고 **4단계**로 가세요.

<!-- 스크린샷: 템플릿 링크를 열었을 때 보이는 '사본 만들기' 화면 -->

### 방법 B — 새로 만들기

1. 구글 드라이브에서 **새로 만들기 → Google 스프레드시트**로 빈 시트를 만들어요. (주소창에 `sheets.new`를 입력해도 돼요)
2. 왼쪽 위 제목을 "내 자산 시세"처럼 알아보기 쉽게 바꿔요.

## 2단계. 코드 붙여넣기

1. 시트 위쪽 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요. 새 탭에 코드 편집기가 열려요.
2. 편집기에 원래 있던 내용(`function myFunction() { }`)을 **모두 지워요**.
3. 아래 코드를 **전부** 복사해서 붙여넣어요.
4. 디스크 모양 **저장** 버튼을 눌러요. (또는 Ctrl+S, 맥은 ⌘+S)

## 3단계. 시트 기본 틀 만들기

1. Apps Script 편집기 위쪽의 함수 선택 칸에서 **setupSheet**를 고르고 **실행**을 눌러요.
2. 처음에는 **승인 필요** 창이 떠요. **권한 검토**를 누르고 내 구글 계정을 골라요.
3. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동(안전하지 않음) → 허용**을 눌러요.
4. 시트 탭으로 돌아가면 **시세** 탭이 생기고, 제목 줄(티커·가격·통화)과 예시 줄이 들어 있어요.

> **이런 경고가 왜 나오나요?** 내가 직접 붙여넣은 코드라서 구글의 심사를 받지 않았기 때문이에요. 이 코드는 내 시트를 읽고(처음 한 번 기본 틀을 만들 때만 시트를 고쳐요) 시세를 보여주는 일만 해요. 다른 곳으로 정보를 보내는 기능은 없어요.

## 4단계. 내 티커 적기

1. **시세** 탭의 A열에 앱에 입력한 티커를 **똑같이** 적어요. 예시 줄(`KRX:005930`, `NASDAQ:QQQ`)은 내 종목으로 바꾸거나 지워요.
2. 티커를 적으면 B열(가격)과 C열(통화)에 수식이 자동으로 들어가요. 잠시 뒤 숫자가 보이면 성공이에요.
3. 2행의 `CURRENCY:USDKRW`는 **달러 환율**이에요. 지우지 마세요.

티커 적는 법:

- 국내 주식·ETF: `KRX:005930` (코스닥 종목은 `KOSDAQ:247540`)
- 미국 주식·ETF: `NASDAQ:QQQ`, `NYSEARCA:SCHD`, `NYSE:KO`처럼 **거래소:종목코드**

> 가격 칸에 `#N/A`가 보이면 티커 형식이 틀렸거나 구글 금융에서 지원하지 않는 종목이에요. 거래소 이름을 확인해 보세요. 그래도 안 되면 앱에서 그 종목의 현재가를 직접 입력하면 돼요.
>
> 수식이 자동으로 안 들어가면 위쪽 아무 종목 줄의 B·C 칸을 복사해서 새 줄에 붙여넣으세요.

<!-- 스크린샷: 티커를 적은 시세 탭 (A열 티커, B열 가격, C열 통화) -->

## 5단계. 웹 앱으로 배포하기

1. Apps Script 편집기 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. **유형 선택**(톱니바퀴)에서 **웹 앱**을 골라요.
3. 설명은 아무거나 적어도 돼요. (예: 시세)
4. **다음 사용자 인증 정보로 실행**은 **나**로 둬요.
5. **액세스 권한이 있는 사용자**는 꼭 **모든 사용자**를 골라요. "Google 계정이 있는 모든 사용자"를 고르면 앱이 시세를 읽지 못해요.
6. **배포**를 눌러요. 권한을 물어보면 3단계처럼 허용해요.

<!-- 스크린샷: 새 배포 창 (웹 앱, 실행: 나, 액세스: 모든 사용자) -->

## 6단계. 앱에 주소 붙여넣기

1. 배포가 끝나면 **웹 앱 URL**이 보여요. `https://script.google.com/macros/s/…/exec`로 끝나는 주소를 **복사**해요.
2. 앱의 **설정 → 시세 연결 → 내 구글 시트 웹 앱 주소**에 붙여넣어요.
3. **연결 테스트**를 눌러 "연결됐어요!"가 나오면 끝이에요.

이제 앱을 열 때마다 시세를 한 번 받아오고, 화면 위쪽의 시세 시각을 누르면 다시 받아와요.

## 자주 묻는 질문

### 종목을 새로 샀어요

앱에 종목을 추가하고, 시트 A열에도 같은 티커를 한 줄 추가하세요. 다시 배포할 필요는 없어요.

### 연결 테스트가 실패해요

- 주소가 `/exec`로 끝나는지 확인하세요. (편집기 주소나 `/dev` 주소가 아니에요)
- 배포할 때 액세스 권한을 **모든 사용자**로 했는지 확인하세요. 바꾸려면 **배포 → 배포 관리 → 수정(연필)**에서 고치고 **배포**를 누르세요.
- 시트에 **시세** 탭이 있고, 1행이 제목 줄인지 확인하세요.
- 인터넷 연결을 확인하세요.

### 코드(Code.gs)를 새 버전으로 바꿨어요

**배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누르세요. 주소는 바뀌지 않아요.

### 웹 앱 주소가 다른 사람에게 알려지면?

주소를 아는 사람은 시트의 **티커와 시세**를 볼 수 있어요. 수량·금액은 시트에 없으니 내 자산 규모가 드러나지는 않지만, 어떤 종목을 가졌는지는 알 수 있어요. 주소는 나만 알고 있는 게 좋아요. 걱정되면 **배포 → 배포 관리**에서 지금 배포를 **보관처리**하고 새로 배포한 뒤, 새 주소를 앱에 붙여넣으세요.

### 내 수량·금액 정보는 어디에 있나요?

이 기기의 브라우저에만 저장돼요. 앱은 시트에서 시세를 받아오기만 하고, 내 정보를 보내지 않아요.

## 템플릿 시트 만들어 공유하기 (앱을 알려주는 사람용)

지인이 코드를 붙여넣지 않고 바로 시작할 수 있게 템플릿을 만들어 둘 수 있어요.

1. 방법 B로 새 시트를 만들고 2~3단계를 마쳐요. **내 종목은 적지 말고** 예시 줄만 남겨 두세요.
2. 오른쪽 위 **공유**에서 일반 액세스를 **링크가 있는 모든 사용자(뷰어)**로 바꾸고 링크를 복사해요.
3. 링크 끝의 `/edit…` 부분을 `/copy`로 바꿔서 지인에게 보내요. 예: `https://docs.google.com/spreadsheets/d/(시트ID)/copy`
4. 지인은 링크를 열고 **사본 만들기**만 누르면 시트와 코드가 함께 복사돼요. 단, 배포는 복사되지 않으니 **5단계부터는 각자** 해야 해요.
